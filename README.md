# Math Masterclass Studio

Quero criar um site moderno, profissional e responsivo para um professor de Matemática que disponibiliza aulas gravadas.

IMPORTANTE:

Neste primeiro momento, quero criar um PROTÓTIPO VISUAL COMPLETO do site.

Não implemente banco de dados real, autenticação real, pagamentos ou backend complexo ainda.

Use dados fictícios/mockados para demonstrar todas as funcionalidades visualmente.

O objetivo principal desta primeira versão é avaliar o DESIGN, UX, navegação, organização das páginas e experiência do aluno.

O site deverá estar preparado estruturalmente para receber backend posteriormente.

==================================================

1. IDENTIDADE E ESTILO

==================================================

O site deve transmitir:

- Educação

- Matemática

- Tecnologia

- Organização

- Profissionalismo

- Modernidade

Evite aparência de "site escolar antigo".

Quero uma interface semelhante a uma plataforma moderna de cursos, mas sem copiar visualmente nenhuma plataforma específica.

Priorize:

- Layout limpo

- Excelente espaçamento

- Cards modernos

- Tipografia profissional

- Hierarquia visual clara

- Microinterações discretas

- Animações suaves

- Excelente experiência em celular

- Excelente experiência em desktop

- Dark mode bem desenvolvido

A interface deve parecer um produto real pronto para lançamento.

Não exagerar em animações.
